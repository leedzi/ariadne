## 总结规则

请将下方的对话内容，按照【关键词记忆法】总结为结构化的长期记忆。请严格遵守以下格式和要求：

### 1. 摘要 (Summary)
- **目标**：对已发生事件的精准总结。
- **要求**：
    - 尽量少的使用token，精准简洁陈述角色言行/心理活动/伏笔计划。
    - 保留核心对话原句与情报细节。
    - 明确起因→行动→结果。
    - 不使用括号解释，忠实记录互动与剧情进展。
    - 将核心道具/关键誓言/转折性名词等用【】包裹。

### 2. 情感/关系更新 (Relationship Update)
- **目标**：记录这段互动后，角色对用户情感或关系的微妙变化。
- **要求**：
    - 记录信任度、亲密度的增减。
    - 记录角色对用户的新看法或刻板印象的改变。
    - 记录双方达成的默契或共同的秘密。
    - 格式：`【角色对用户的看法|情感倾向|信任度变化|特殊关系纽带】`

### 3. 关键记忆 (Key Memories)
- **目标**：记录对未来的长期影响。
- **要求**：
    - 仅保留最近或影响最深远的4-5个节点。
    - 格式：`【角色|时间|地点|环境|具体关键事件|由此产生的转变/经验/承诺/新创伤/关系突破点/影响|人际关系变化|对当下的具体约束】`

### 4. 原文摘录 (Quotes)
- **目标**：如果你认为需要，可以保留最触动人心或最具信息量的原话。
- **要求**：
    - 仅摘录几句最关键的台词（用户或角色的均可）。
    - 原文，不要修改。
    - 格式：`【说话人】“原文内容”`
